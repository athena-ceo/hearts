So far I’ve been restoring what we built. From here the question changes: can AI find a better way to play this game than the rules we wrote in 1986? We tried four things, each measured the same way, in one seat against three 1986 Experts on fixed deals. Lower is better. Here’s the result up front. The self-play network wins on points, by a wide margin, and can’t tell you why. Rules written by comparing with it win among the players that can explain themselves, but they recover only about 15% of its gain. An LLM per move can’t be told apart from the Expert on a small sample, and it costs real money for each decision. Better knowledge of opponents’ voids gained nothing, because the rules as written barely use it. One caution: the number of deals differs by row, and these are all against identical Experts.
