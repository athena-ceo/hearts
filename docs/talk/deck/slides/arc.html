Three questions, in the order they came up

1. Sections 1 to 3

Can a 1986 expert system run again?

Yes. From 78 scanned pages, the whole game runs on current Medley, with its 97 rules as written.

2. Section 4

Can AI play the game better than those rules?

A small neural network does, by a wide margin, but gives no reasons. A language model asked for each card does not, on a small sample.

3. Sections 4 to 6

Can what the AI learned go back into rules people can read?

Partly. Rules written from the comparison recovered about 15% of the network’s gain. This is the question Athena cares about.

Who did what

Ramana Rao and I wrote HEARTS in 1986. In 2026 I set the direction and judged the results, and Claude Code read the scans, wrote the code and ran Medley.

Three different AIs appear

Claude Code: the coding agent that did the revival work. The LLM player: a language model asked which card to play. The network: a small neural net that taught itself the game by self-play.
