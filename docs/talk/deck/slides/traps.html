Traps an agent will fall into

(* ...) inside a DEFINEQ defines a function named *, and breaks every later comment.

REM.CM is honored only if it begins with a double quote.

TERPRI on a process stream sends CR, and long writes to stdin lost bytes. Use a file.

Exec windows stop when full, until PAGEFULLFN is advised.

SHOULDNT is an unconditional break. NLSETQ doesn’t catch it, so the game just freezes.

Headerless files must be loaded from an Interlisp exec, or (* ...) reads as Common Lisp.
