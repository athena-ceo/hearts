The deductions are sound

Lisp and Python agreed on all 780 positions, and 9,360 bounds all held against the real hands.

Better voids didn’t help

Deduced voids changed nothing (−0.01). Even the true voids gained nothing (+0.12, −0.16 to +0.43). Only five rules read voids, and none of them minimizes.

I’d proposed this in my 1986 write-up, so I had to try it. It works as logic, and gained nothing as played, because the rules as written have nowhere to use the knowledge. That is a finding about knowledge engineering, too: knowing more doesn’t help a rule base that doesn’t ask. New rules built on voids didn’t beat what was there.
