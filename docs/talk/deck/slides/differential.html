Can a trained network show where a rule base is weak? This is differential analysis, and it’s the part I find most interesting. Whole games diverge at the first different card, so you replay the Expert’s own games and ask the network what it would do. Then the hybrid seat tells you which disagreements actually cost points. The answer here: leads, and how the Expert plays after it decides to shoot. With all kinds on, the hybrid scored the same as the pure network on all 1,000 deals, so the swap doesn’t disturb the game.
