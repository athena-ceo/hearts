# Talk deck: HEARTS, forty years on

The slide sources for the talk given to the Medley Interlisp user group on 11 November 2026.

- `deck.json` is the index: the title, the slide order, the sections and the typefaces.
- `slides/<id>.html` is one slide each: a single `<section>` on a 1920×1080 canvas, with the speaker notes
  in its `<aside>`.

These are a copy of a Claude Slides deck, which is where the deck is edited and presented. The images
(screenshots, the logo, the 1986 rule listing) are stored with that deck and are referenced here as
`/_blob/<id>`, so the files in this folder do not render on their own.
